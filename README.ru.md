<h1 align="center">Sova</h1>

<p align="center"><b>Макбук не засыпает с закрытой крышкой. Один переключатель в строке меню.</b><br>
Бесплатно, открытый код · Apple Silicon и Intel · macOS 13+ · <a href="README.md">English</a></p>

Закрываешь макбук без внешнего монитора, и macOS засыпает: загрузка обрывается, сборка встаёт,
ИИ-агент замирает на полпути. `caffeinate` от этого не спасает, он мешает только засыпанию
по бездействию. `sudo pmset -a disablesleep 1` работает, но остаётся включённым, пока не вспомнишь
выключить, а мак без сна в рюкзаке греется.

Sova делает то же самое через переключатель и сама возвращает сон, когда нужно.

## Установка

```bash
brew install --cask Rivi398/tap/sova
```

Или скачай `Sova-x.y.z.zip` в [Releases](https://github.com/Rivi398/sova/releases),
перетащи `Sova.app` в «Программы» и один раз выполни:

```bash
xattr -dr com.apple.quarantine /Applications/Sova.app
```

Sova не проверена Apple (для этого нужен платный аккаунт разработчика), поэтому без этой команды
macOS её не откроет. Homebrew делает этот шаг сам.

## Как пользоваться

Нажми на сову в строке меню и включи **«Не засыпать с закрытой крышкой»**.

- Сова с закрытыми глазами: обычный сон.
- Зелёная сова с открытыми глазами: мак не засыпает с закрытой крышкой, в том числе от батареи.

При первом включении macOS один раз спросит пароль (зачем, написано ниже).

## Сон всегда возвращается

Sova сама включает сон обратно, если:

- ты выключил переключатель или вышел из Sova;
- батарея опустилась ниже порога (по умолчанию 20%, меняется в меню);
- мак перегрелся (температурное состояние macOS *serious* или *critical*);
- Sova упала, её закрыли принудительно или мак перезагрузился. Для этого есть маленький системный
  сторож: при загрузке и раз в минуту он проверяет, и если сон выключен, а Sova не запущена,
  возвращает сон.

## Зачем пароль

Управлять сном при закрытой крышке может только администратор. Sova не держит постоянно
запущенного помощника с правами root, а один раз ставит два маленьких файла:

| Файл | Что делает |
|---|---|
| `/etc/sudoers.d/sova` | разрешает твоему пользователю без пароля ровно две команды: `pmset -a disablesleep 0` и `pmset -a disablesleep 1`. Больше ничего. |
| `/Library/LaunchDaemons/ru.studiasok.sova.guard.plist` | сторож: при загрузке и раз в 60 секунд, если сон выключен, а Sova не запущена, выполняет `pmset -a disablesleep 0`. |

Оба файла создаются в [`Sources/Sova/System.swift`](Sources/Sova/System.swift), правило sudo
перед установкой проверяется `visudo`. Проверить можно самому: `sudo -n pmset -a disablesleep 0`
проходит без пароля, а `sudo -n pmset -a sleep 0` уже нет.

Sova не ходит в интернет, не собирает статистику и не требует аккаунтов.

## Удаление

Меню → **«Удалить системные настройки…»**, потом перетащи Sova в Корзину.
Через Homebrew: `brew uninstall --cask sova` удаляет всё сразу.

Руками:

```bash
sudo pmset -a disablesleep 0
sudo launchctl bootout system/ru.studiasok.sova.guard
sudo rm /etc/sudoers.d/sova /Library/LaunchDaemons/ru.studiasok.sova.guard.plist
```

## Сборка из исходников

Нужны только Command Line Tools (`xcode-select --install`), Xcode не нужен:

```bash
scripts/build.sh          # → dist/Sova.app и dist/Sova-<версия>.zip
```
